# قبول البنية التحتية للوكلاء المحليين

## النطاق

هذا المستند يثبت فقط إصلاحات البنية التحتية قبل تفويض أي ميزة إنتاجية:

1. تشغيل الوكيل داخل عملية ابن مستقلة، مع `taskkill /PID <pid> /T /F` عند انتهاء المهلة.
2. بوابة حتمية بلا نموذج لغوي: نطاق `Target Files`، قابلية تطبيق patch، static lint،
   production build، واختبار القبول المحدد في البطاقة.
3. نقل الأعطال التشغيلية إلى `needs-human/` واستمرار الطابور، بدلاً من إيقافه أو
   طلب تشخيص فوري من Codex.

## دليل الاختبار

شغّل الاختبار المعزول التالي:

```powershell
./tools/test-local-agent-infrastructure.ps1
```

نتيجة القبول المطلوبة:

- يختفي PID الأب والابن خلال 8 ثوانٍ أو أقل بعد `taskkill /T /F`.
- ترفض البوابة patch يلمس `package.json` عندما تذكر البطاقة `src/App.tsx` فقط،
  قبل أي بناء أو اختبار أو استدعاء نموذج.

كما يجب أن يمر المشروع نفسه من:

```powershell
npm run lint
npm run build
```

## حدود مقصودة

- لا يدمج هذا المسار أي patch تلقائيًا.
- لا تُرسل ملفات المشروع خارج الجهاز.
- لا تبدأ مهام حقيقية إلا ببطاقة تحتوي `Target Files` و`Source anchors` و
  `Acceptance test commands` صريحة.
