## C2.1 — Forecast-aware activity comparison register

## الهدف التشغيلي

إظهار Baseline المعتمد والخطة الحالية وتوقع CPM للنشاط نفسه في سجل واحد قابل
للتتبع، دون أن يغير العرض أي تاريخ مخطط أو Baseline. هذه وحدة محدودة من C2 وليست
إغلاقًا كاملًا لميزة مقارنة النسخ.

## مصدر الحقيقة والحدود غير القابلة للتعديل

- Baseline: `BaselineActivitySnapshot` المعتمد.
- Current: صف النشاط الحي.
- Forecast: صف CPM/الحالة الذي يحمل `forecast_start_date` و`forecast_end_date` و`network_critical`.
- لا تعديل للـBaseline أو planned/current dates، ولا تغيير schema أو UI.

## معايير القبول

1. للـactivity code نفسه يعرض السجل Baseline وCurrent وForecast، مع فرق نهاية Forecast عن Baseline بالأيام وCritical منفصل.
2. عند غياب Forecast يعرض `Unavailable` وقيم Forecast `null`، ولا يستخدم Current كـForecast صامت.
3. لا تغير المقارنة أي كائنات مصدر.
