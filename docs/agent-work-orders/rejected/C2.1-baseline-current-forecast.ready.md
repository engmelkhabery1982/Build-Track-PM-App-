# بطاقة عمل محكومة للوكلاء المحليين

## C2.1 — Activity-level baseline/current/forecast comparison model

## الهدف التشغيلي

إظهار سجل فروق نشاط يمكن لمدير المشروع مراجعة أثره الزمني دون تغيير الخطة
المعتمدة: Baseline مقابل Current Plan مقابل CPM Forecast، لتحقيق رقابة قابلة
للتدقيق تقارب وظيفة SAP PS.

## مصدر الحقيقة والحدود غير القابلة للتعديل

- الـBaseline المجمد في `BaselineActivitySnapshot` هو الحقيقة التاريخية.
- Current Plan هو حقول النشاط الحية؛ Forecast هو `forecast_start_date` و
  `forecast_end_date` الناتجان عن CPM فقط.
- ممنوع الكتابة على Baseline أو `start_date`/`end_date` المخططة، وممنوع اختراع
  Forecast عندما لا توجد حقول CPM.

## معايير القبول

1. توسع `compareBaselineActivityDetails` و`BaselineActivityVariance` لعرض
   Baseline وCurrent وForecast بصورة منفصلة للتواريخ والمدة والمسار الحرج.
2. تبقى حالة النشاط Added/Removed/Changed/Unchanged مبنية على Baseline مقابل
   Current، بينما يعرض غياب Forecast صراحةً كـUnavailable/null لا كقيمة مخترعة.
3. لا يتغير السلوك القائم لمقارنة الكمية والميزانية والتقويم أو
   `predecessor_links` عبر `stableJson`.
4. يتضمن patch اختبارًا مقترحًا لحالة CPM Forecast متغير وحالة Forecast غائب.
